# hc-board

Живая доска AI-агентов, запущенных через [herdr-core](https://herdr.dev) (`hc`), и запуск агентов
из вкладок VS Code. Windows, PowerShell 5.1+.

```

┌ Mods - claude ──────────┐  ┌ DragonGame - claude - аниматор ┐  ┌ DragonGame - codex ─────┐
│ ревью HSKFixes          │  │ А уши тогда ?                  │  │ Нарисуй схемы поз рук   │
│   Trust this folder?    │  │   ● Теперь анимации ушей:      │  │   • Открыл схемы поз…   │
│   ❯ 1. Yes              │  │   ✶ Contemplating… (57s)       │  │   Worked for 8s         │
│   2. No                 │  │                                │  │                         │
│ blocked            ⏱ 4s │  │ working                ⏱ 1m 07s│  │ done           ⏱ 2m 11s │

```

## Файлы

| Файл | Что делает |
|---|---|
| `hc-board.ps1` | Доска: карточки агентов в колонках NEEDS YOU / WORKING / DONE |
| `hc-agent.ps1` | Подключает консоль к терминалу `hc` с данным именем; запускает его, если он не идёт |
| `examples/vscode-tasks.json` | Пример `.vscode/tasks.json`: агенты и доска стартуют при открытии папки |

## Доска

```powershell
powershell -NoProfile -File .\hc-board.ps1
```

Колонки берутся из статуса, который агенты (Claude Code, Codex, Kimi) сообщают `hc`:

| Колонка | Статусы |
|---|---|
| NEEDS YOU | `blocked`, `error`, а также упавший терминал (код выхода не 0) |
| WORKING | `working` |
| DONE | `done` (зелёный, сверху), `idle` (голубой) |

Карточка: заголовок `проект - агент - роль`, последний запрос агенту и время в текущем статусе.
У работающих и ждущих вас агентов (WORKING, NEEDS YOU) ещё последние строки их вывода,
они обновляются на лету; у DONE их нет.

- **Роль** — метка `hc label <имя> role=<роль>`.
- **Последний запрос** читается с экрана агента (`❯ …` у Claude, `› …` у Codex); задача от другого
  агента показывается как «от <имя>: …».
- `done`, бывший до запуска доски, считается просмотренным и показывается как `idle`.
- Скрыты: обычные программы без статуса (`p`), нормально завершённые терминалы (`f`),
  `idle` дольше 20 минут (`i`).

Клавиши: `q` выход, `p` / `f` / `i` показать скрытое, `r` перечитать.

Параметры: `-ShowPlain`, `-ShowFinished`, `-IdleHideMinutes 20`, `-TailLines 3`, `-TailSeconds 2`,
`-RefreshSeconds 15`, `-Once` (нарисовать один раз и выйти).

Доска перечитывает `hc ls` по событиям `hc events`, а экраны агентов — только у работающих
(раз в `-TailSeconds`) или когда у агента сменился ход.

## Агенты из вкладок VS Code

```powershell
hc-agent.ps1 [--role <роль>] <имя> <папка> <команда> [аргументы...]
```

Если терминал `<имя>` уже идёт, вкладка подключается к нему; если нет — запускает его через
`hc run --bg --outlive-parent` и подключается. Агенты переживают закрытие VS Code, а при следующем
открытии вкладки находят их снова. `ctrl+\` отключает вкладку, агент продолжает работать.

См. `examples/vscode-tasks.json`. Замечания:

- Задачи типа `process` (без оболочки), `"echo": false` — иначе VS Code пишет строку
  `Executing task` над агентом.
- Два Claude в одной папке не должны оба запускаться с `--continue`: каждый продолжает свою
  сессию через `--resume <id>`.
- Codex запускается с `--no-daemon`, иначе его команды выполняются вне `hc`.

## Скрипты и кодировка

Файлы `.ps1` сохранены в UTF-8 **с BOM**: Windows PowerShell 5.1 читает файл без BOM как ANSI и
ломает рамки и кириллицу.
